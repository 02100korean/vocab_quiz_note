언어별 검수 엔진 (선택)

비워 두면(기본) 위의 "검수 엔진"을 써요. 비교해 본 뒤 언어마다 잘 맞는 엔진을 고르고, 메모에 적어 두세요.

키와 모델 이름은 이 브라우저에만 저장돼요. 모델 이름은 각 회사에서 쓰는 이름으로 바꿀 수 있어요. 검수는 번역된 칸을 다시 보고 고칠 것만 고쳐요.

대상 교재 (새 교재는 이름만 쓰면 ID가 자동으로 만들어져요)
교재 이름에 쓸 수 있는 것: 한글 · 영문 · 숫자 · 띄어쓰기 · 기호는 - _ 만 (파일 이름에 그대로 쓰여요)

사이트에 등록

기존 교재 검수 (검수 결과를 확인한 뒤 선택한 것만 반영해요)
파일로 받아 고치기

Excel·JSON은 고쳐서 다시 올릴 수 있고(id 열은 그대로 두세요), 올리면 바뀐 칸·새 줄·지운 줄만 확인 표로 보여 줘요. Word는 보기·인쇄용이라 올릴 수 없어요. 위 소단원을 고르면 그 소단원만 받아요.

위 "다국어"에서 체크한 언어의 번역을 검수 엔진(위 설정)이 다시 보고 고칠 것만 제안해요. 이미 채워진 번역만 검수해요.

기존 교재 번역 추가 · 백업

위 "다국어"에서 체크한 언어 중 비어 있는 칸만 번역해요(50개씩). 한도에 걸리면 잠시 기다렸다가 이어서 해요. 등록하거나 바꿀 때는 직전 내용이 JSON 파일로 자동 저장돼요.

번역 결과 등록: 위에서 번역한 단어를 이 교재에 추가해요(같은 소단원·같은 단어는 새 것으로 바꿔요). JSON 파일 올리기: 교재 전체를 파일 내용으로 바꿔요.

번역·검수 결과는 결과 보기 팝업에서 확인해요 (엑셀 받기 · 인쇄/PDF · 수정한 엑셀 올리기 · 검수 요청 문구 복사).
